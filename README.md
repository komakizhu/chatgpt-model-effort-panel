# Safari ChatGPT：模型与档位悬浮面板

版本：0.7.0。此 Safari Userscripts 脚本只匹配 `https://chatgpt.com/*` 顶层页面，通过 ChatGPT 页面当前可读的模型与强度状态工作。

## 使用

- 页面右下角默认显示一行已经网页核对的模型与强度；点右侧三角展开简洁面板，顶部继续显示当前已确认值，下面并排显示 GPT-5.6 与 GPT-6，再以两行显示 Low、Mid、High、X High、Pro。折叠态布局不变。
- 展开面板可使用“开启／关闭”总开关；折叠时隐藏开关，关闭后仍可展开并重新开启。关闭期间不读取页面模型或档位、不打开菜单、不切换模型、不保存聊天选择；重新开启会重新读取当前页面。开关状态保存在浏览器中并在同源标签页间同步，首次默认开启。设置损坏或无法读取时会默认停用并显示原因；存储写入失败时当前标签页仍会按用户操作启停，并显示没有保存成功。
- 折叠面板在没有鼠标悬停、键盘焦点或拖动的情况下闲置 5 秒后变为半透明；重新操作时恢复清晰，半透明时仍可点击。
- 折叠态宽度控制在 148px 以内（约为旧版的 75%），默认停在录音按钮右侧的底部留白，不遮挡录音按钮；展开态保留 198px 宽度。面板上除控件外的空白区域都可以拖动。聚焦顶部摘要后按方向键移动，按住 Shift 可加快。面板位置和折叠状态保存在当前浏览器中。
- 展开面板后，脚本会等页面空闲再读取模型列表，并只关闭自己打开的菜单。读取会因输入、生成或用户操作而延后或取消；账号权限和用量限制照常生效。
- 折叠摘要只显示页面已经读到的真实档位名称，例如 `GPT-5.6 · Medium`。页面没有可确认的名称时显示“档位未识别”，不会把序号伪装成“原生第 N 档”。
- 面板选择经页面确认后，会保存为当前聊天偏好和新聊天默认。首次默认是 **GPT-5.6 Sol + Medium**；已有聊天继续使用自己的偏好。原生菜单手动选择和脚本自动同步只更新当前聊天，不改全局默认。强度未确认时不会改新聊天默认。
- 页面确认后，聊天偏好和全局默认分别保存；任一写入失败都会在面板提示，当前页面仍显示实际生效状态。
- 不提供强度设置的模型会明确显示“此模型没有强度设置”。如果页面没有足够信息确认控件状态，面板会显示未识别并停止自动调整。
- 当前没有找到可确认的强度写入接口和完整选项映射，因此面板强度按钮保持禁用，并说明“未发现可确认的强度写入接口”。脚本只读取页面当前提供的名称和值，不猜档位，不模拟滑杆操作或写入成功。
- 脚本可在用户输入时被动读取页面已经显示的模型与强度；打开原生菜单或切换模型必须等中文输入法组合、普通输入、语音、鼠标操作、生成回复结束，并至少静默 1300ms。模型同步每个状态最多尝试一次必要切换；切换前后用户开始操作时会取消后续自动动作，不恢复旧焦点。按用户确认，空闲后的一次模型切换可能短暂改变焦点。用鼠标点面板选择仍会保留原有焦点；键盘用户仍可通过 Tab、Enter、Space 操作。

模型和强度始终受 ChatGPT 当前账户权限、用量限制及原生菜单状态约束。脚本只确认网页上的选择，不推断服务端最终使用的模型。

## 输入保护与范围

脚本只读取模型菜单、强度控件、当前会话地址及必要的输入事件标记；它不读取聊天正文、不修改网络请求，也不会自动发送消息。输入期间的被动读取不会操作页面；需要切换模型时会等用户空闲。模型偏好无法确认时，脚本会显示原因，不自动改选其他模型。

关闭总开关只停用自动化，不会反向切回其他模型，也不会关闭用户当时已经打开的原生菜单。关闭期间页面发生的变化会在重新开启后重新读取，旧的页面状态缓存不会复用。

## 安装位置

Userscripts 保存目录：

```text
/Users/mac/Library/Containers/com.userscripts.macos.Userscripts-Extension/Data/Documents/scripts/
```

安装或更新时，将完整的 `ChatGPT_56_Preference.user.js` 覆盖到该目录中的同名脚本。打开 Safari 的 Userscripts 弹窗确认显示“ChatGPT 模型与档位”，并在 Safari 设置 → 扩展中启用 Userscripts 和 chatgpt.com 站点访问权限。刷新无未发送草稿的 ChatGPT 页面以加载新版。不要手动改扩展生成的清单文件。

脚本只替换这一份 ChatGPT 专用文件，不更改或停用其他脚本，包括 Poe。撤销时只在 Userscripts 中停用“ChatGPT 模型与档位”。旧版偏好键会保留，以便回退。

本地偏好以 `chatgpt-model-preference-v2:` 为前缀；聊天偏好保存在本机浏览器存储，新草稿的临时偏好只保存在当前标签页。每个档位键都包含所属模型和原生滑杆位置，避免把一个模型的档位位置套到另一个模型。页面状态文案缺失或序号与当前值不一致时，状态保持未识别，不生成序号名称。只有页面真实确认成功的选择才会更新会话偏好；浏览器拒绝写入时只在当前标签页记忆，并明确提示刷新后无法保留；后端写入失败或无法确认响应时保留上一次确认。旧版 `chatgpt-56-preference-v1:` 档位仍会映射为 GPT-5.6 Sol 对应位置。

```sh
node --check ChatGPT_56_Preference.user.js
node --test preference.test.cjs
git diff --check
```

Safari 手动验收应确认：首次展开时模型列表能在页面空闲后读取；模型面板选择经页面确认后会写入当前聊天和新聊天默认；刷新或新聊天继承最后一次确认的组合；已有聊天偏好不变。当前强度按钮应保持禁用，直到页面提供可验证的写入接口和选项映射。不得发送测试消息；遇到限额、权限禁用或无法识别的控件时，只记录页面实际状态。

## Safari 控件核对（2026-11-04）

- ChatGPT 模型按钮的 accessible name 为“选择 ChatGPT 模型”。原生模型项使用 `role="menuitemradio"` 与 `aria-checked`；当前菜单显示 GPT-6 和 GPT-5.6 Sol，GPT-5.6 Sol 为已选项。
- GPT-6 的菜单项没有 `aria-disabled`，但原生菜单在它前方提供屏幕阅读器提示“已锁定，打开访问权限选项”“已达到使用限额”。实现需要一并检查这类紧邻提示，不能只依据 `aria-disabled`。
- GPT-5.6 的强度控件使用 `role="slider"`，范围为 0–4，当前值为 1。菜单的 live status 显示“Medium，第 2 项，共 5 项”；脚本只在页面已经提供该状态时读取名称，不再逐项移动滑杆探测。
- 以上是当前 Safari 页面控件的观察结果。模型菜单会因账号权限和限额变化，脚本不把这次观察当成完整或永久的模型清单。
