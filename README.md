# Safari ChatGPT：模型与档位悬浮面板

版本：0.3.0。此 Safari Userscripts 脚本只匹配 `https://chatgpt.com/*` 顶层页面，通过 ChatGPT 页面当前显示的原生模型与强度控件工作。

## 使用

- 页面右上角会常驻显示“ChatGPT 模型与档位”面板。面板不会收起；选模型或档位后仍保持可见。
- 模型列表读取当前原生菜单，按原顺序显示模型；原生控件提供可访问分类时，面板也会保留分类。面板保留原生名称和不可用提示。模型菜单更新后，可点“重新读取”。受限选项会显示为不可用，脚本不会选择或绕过限制。
- 选择模型后，面板读取该模型实际提供的档位。只有通过原生控件复核的模型与档位才会显示为已确认。
- 点击“设为新聊天默认”会保存当前已经确认的模型和档位。没有历史记录的新聊天首次打开时采用当时的默认组合；已有聊天的选择不会被新的默认覆盖。
- 悬浮面板或 ChatGPT 原生菜单里的手动选择都会按聊天保存在本机。刷新、切走再切回时，脚本会恢复该聊天的选择。
- 不提供强度设置的模型会明确显示“此模型没有强度设置”。如果页面没有足够信息确认控件状态，面板会显示未识别并停止自动调整。

初始默认值为 **GPT-5.6 Sol + Medium**。模型和档位始终受 ChatGPT 当前账户权限、用量限制及原生菜单状态约束。脚本只确认网页上的选择，不推断服务端最终使用的模型。

## 输入保护与范围

脚本只读取模型菜单、强度控件、当前会话地址及必要的输入事件标记；它不读取聊天正文、不修改网络请求，也不会自动发送消息。用户正在输入、使用输入法、操作菜单或生成回复时，脚本会暂停并让用户继续操作；页面空闲后会自动继续核对。模型偏好无法确认时，脚本会显示原因，不自动改选其他模型。

## 安装位置

Userscripts 保存目录：

```text
/Users/mac/Library/Containers/com.userscripts.macos.Userscripts-Extension/Data/Documents/scripts/
```

安装或更新时，将完整的 `ChatGPT_56_Preference.user.js` 覆盖到该目录中的同名脚本。打开 Safari 的 Userscripts 弹窗确认显示“ChatGPT 模型与档位”，并在 Safari 设置 → 扩展中启用 Userscripts 和 chatgpt.com 站点访问权限。刷新无未发送草稿的 ChatGPT 页面以加载新版。不要手动改扩展生成的清单文件。

脚本只替换这一份 ChatGPT 专用文件，不更改或停用其他脚本，包括 Poe。撤销时只在 Userscripts 中停用“ChatGPT 模型与档位”。旧版偏好键会保留，以便回退。

本地偏好以 `chatgpt-model-preference-v2:` 为前缀；聊天偏好保存在本机浏览器存储，新草稿的临时偏好只保存在当前标签页。每个档位键都包含所属模型和原生滑杆位置，避免把一个模型的档位位置套到另一个模型。原生范围可读、但其他名称读不到时，面板用“原生第 N 档”显示该位置；用户选择后，脚本用原生滑杆值确认，并显示页面当前提供的名称。旧版 `chatgpt-56-preference-v1:` 档位会映射为 GPT-5.6 Sol 对应位置，并在应用时通过原生控件核对。

## 检查

```sh
node --check ChatGPT_56_Preference.user.js
node --test preference.test.cjs
```

Safari 手动验收应查看右上常驻面板、当前原生菜单勾选项和强度状态；测试页不要发送消息。遇到限额、权限禁用或无法识别的控件时，记录实际显示结果，不绕过限制。

## Safari 控件核对（2026-11-04）

- ChatGPT 模型按钮的 accessible name 为“选择 ChatGPT 模型”。原生模型项使用 `role="menuitemradio"` 与 `aria-checked`；当前菜单显示 GPT-6 和 GPT-5.6 Sol，GPT-5.6 Sol 为已选项。
- GPT-6 的菜单项没有 `aria-disabled`，但原生菜单在它前方提供屏幕阅读器提示“已锁定，打开访问权限选项”“已达到使用限额”。实现需要一并检查这类紧邻提示，不能只依据 `aria-disabled`。
- GPT-5.6 的强度控件使用 `role="slider"`，范围为 0–4，当前值为 1。菜单的 live status 显示“Medium，第 2 项，共 5 项”；脚本逐项读取实际名称并恢复原值。
- 以上是当前 Safari 页面控件的观察结果。模型菜单会因账号权限和限额变化，脚本不把这次观察当成完整或永久的模型清单。
